🚀 QUICKEST DEPLOYMENT (2 minutes - RECOMMENDED)
════════════════════════════════════════════════════════════════════════════

VERCEL:
  1. git push origin main
  2. Go to https://vercel.com
  3. Click "New Project"
  4. Select your GitHub repository
  5. Add 7 Firebase environment variables (copy from .env.example)
  6. Click "Deploy"

✅ DONE! Your site is live!

🔐 ENVIRONMENT VARIABLES NEEDED
════════════════════════════════════════════════════════════════════════════

Add these 7 variables to each deployment platform:

  1. VITE_FIREBASE_API_KEY
  2. VITE_FIREBASE_AUTH_DOMAIN
  3. VITE_FIREBASE_PROJECT_ID
  4. VITE_FIREBASE_STORAGE_BUCKET
  5. VITE_FIREBASE_MESSAGING_SENDER_ID
  6. VITE_FIREBASE_APP_ID
  7. VITE_FIREBASE_MEASUREMENT_ID

Get these from: Firebase Console → Settings → Project Settings
