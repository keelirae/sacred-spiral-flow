🎯 FIRST TIME SETUP (Pick One - All are Easy!)

╔════════════════════════════════════════════════════════════════════════════╗
║ OPTION 1: Run Locally (Fastest Development)                               ║
╚════════════════════════════════════════════════════════════════════════════╝

1. Open Terminal in project folder
2. Type:
   npm install
   npm run dev

3. Open browser: http://localhost:5176

4. Dashboard auto-loads with live reload (HMR)

✅ Done in 2 minutes!

╔════════════════════════════════════════════════════════════════════════════╗
║ OPTION 2: Deploy to Vercel (Free Cloud Hosting)                          ║
╚════════════════════════════════════════════════════════════════════════════╝

1. Push to GitHub:
   git push origin main

2. Go to: https://vercel.com

3. Click: "New Project"

4. Select: Your GitHub repository

5. Click: "Deploy"

6. Add Environment Variables:
   - Go to: Settings → Environment Variables
   - Add these from your .env.local file:
     VITE_FIREBASE_API_KEY = (your key)
     VITE_FIREBASE_AUTH_DOMAIN = (your domain)
     VITE_FIREBASE_PROJECT_ID = (your project id)
     VITE_FIREBASE_STORAGE_BUCKET = (your bucket)
     VITE_FIREBASE_MESSAGING_SENDER_ID = (your id)
     VITE_FIREBASE_APP_ID = (your app id)
     VITE_FIREBASE_MEASUREMENT_ID = (your measurement id)

7. Done! Your site is live!

✅ Done in 1 minute!

╔════════════════════════════════════════════════════════════════════════════╗
║ OPTION 3: Use Lovable AI Platform (For AI-Assisted Development)          ║
╚════════════════════════════════════════════════════════════════════════════╝

1. Go to: lovable.dev (or your AI platform)

2. Create New Project

3. Select: "Import from Git"

4. Choose: Your GitHub repository

5. Platform auto-detects React + Vite

6. Click: "Import"

7. In terminal:
   npm install
   npm run dev

8. Your app is ready for AI-assisted development!

✅ Done in 30 seconds!

╔════════════════════════════════════════════════════════════════════════════╗
║ OPTION 4: Use Netlify (Alternative Cloud Hosting)                        ║
╚════════════════════════════════════════════════════════════════════════════╝

1. Go to: https://netlify.com

2. Click: "Add new site" → "Import an existing project"

3. Select: Your GitHub repository

4. Build settings auto-fill:
   - Build command: npm run build
   - Publish directory: dist

5. Click: "Deploy site"

6. Add Environment Variables:
   - Go to: Site settings → Environment variables
   - Add your Firebase credentials

7. Done! Your site is deployed!

✅ Done in 3 minutes!

📁 WHAT'S IN THE FOLDER?

src/
  App.tsx              ← Main app routing
  components/          ← React components
  pages/               ← Page files
  hooks/               ← Custom React hooks
  lib/                 ← Utilities

public/                ← Images, robots.txt
dist/                  ← Built files (after npm run build)

vite.config.ts         ← Build configuration
tailwind.config.ts     ← Style configuration
package.json           ← Dependencies & scripts

.env.example           ← Environment template (COPY TO .env.local)
.env.local             ← Your secrets (DON'T COMMIT THIS!)

════════════════════════════════════════════════════════════════════════════════

🔐 ENVIRONMENT VARIABLES (IMPORTANT!)

1. Copy .env.example to .env.local:
   cp .env.example .env.local

2. Get Firebase credentials:
   - Go to: https://console.firebase.google.com
   - Click your project
   - Settings → Project Settings
   - Copy Web App credentials

3. Paste into .env.local:
   VITE_FIREBASE_API_KEY=your_key_here
   VITE_FIREBASE_AUTH_DOMAIN=your_domain.firebaseapp.com
   ... (all 7 variables)

4. Save .env.local (never commit this file!)

✅ Now you're connected to Firebase!

🆘 QUICK TROUBLESHOOTING

❌ "npm: command not found"
   → Install Node.js from https://nodejs.org (18+ required)

❌ "Port 5176 already in use"
   → Kill: Get-Process node | Stop-Process -Force (Windows)
   → Or change port in vite.config.ts

❌ "Module not found" errors
   → Run: rm -rf node_modules package-lock.json && npm install

❌ Firebase not working
   → Check all 7 env vars are in .env.local
   → Verify Firebase project is active
   → Check browser console for errors

❌ Build fails
   → Run: npm run type-check
   → Run: npm run lint
   → Check error messages carefully
